jin

source

jin turns an Android phone into a small bot host for Delta Chat. It makes the bot its own chatmail account, answers messages in the chats you invite it to, and delivers webxdc apps (.xdc files) to those chats. It all runs on the phone. The only network traffic is mail to the public chatmail relay.

Download jin for Android v0.5.3 Release notes

Jin needs a phone: the bot is an Android foreground service, so it cannot run inside a web page. This page is the explanation and install guide, with a separate slow demo below. Test release; real-device behavior is still being checked.

Install

  1. On your phone, open the download button above (or scan the code below from another screen). It saves jin-v0.5.3.apk.
  2. Open the file. If Android asks, allow installs from your browser or files app for this one install.
  3. Optional: check the SHA-256 is d518a324760c39e65575ee161431cae0107385c7e0625cb4098ae80f4253569a.
  4. Install Delta Chat on the phone or computer you will chat from.

Set up your own bot

  1. Create bot account. One tap, one time. jin makes one dedicated chatmail profile for the bot. It is never your personal account; the address shows in the app.
  2. Start bot. A permanent notification keeps the foreground service running. Stop writes a real stop.
  3. Show invitation QR. jin draws the bot's Delta Chat contact QR on demand. Scan it from another device, or tap "Open in DeltaChat" on the same phone, then send the bot any message.
  4. Add the bot to chats. Each group gets its own shared list, each direct chat its own personal list.
  5. Publish an app version. Pick an .xdc file and the bot sends it to every chat it serves.

Send any ordinary text and it echoes it back (up to 2,000 characters). Commands: add buy milk, list, done 1, clear, help. Each chat has its own small list. This demo does not publish webxdc apps, control your phone or connect to Bidik.

Runs daily at 03:17 UTC (10:17 WIB). GitHub disables schedules after 60 days without repository activity, such as commits. Its cache may be evicted, losing this demo account and lists; the invite would need replacing after re-provisioning. Lists may reset at any time. Limits: 20 items per chat, 200 characters per item, 200 chats; at most 5 replies per chat and 60 total per run, excess messages are dropped. No guaranteed response time. Demo details and recovery.

Android bot trust and limits

  • Contact requests are refused. Only holders of the invitation QR get in.
  • No chat can publish or administer the bot; all management is in the app.
  • Each chat's data is kept apart from every other chat's.
  • When the bot is removed from a chat, access pauses; re-adding resumes the same list.
  • Android only (arm64). The bot is on only while the service runs, so a phone that is off or has killed the service will not answer.
